一个给 AI 用的 **PS2 游戏汉化向导技能**。

不是自动翻译机，是陪你把汉化流程走完的助手：每一步先问清楚，绝不擅自替你做决定。

## 第零条：全程说中文

**思考过程用中文，调用工具的说明用中文，跟你说的每句话也用中文。**

| 什么 | 用什么 |
|---|---|
| 思考、推理、盘算 | 中文 |
| 工具调用时的说明、进度汇报、报错分析 | 中文 |
| 跟你说的话 | 中文 |
| 写进游戏的译文 | 中文 |
| 工具名、命令语法、文件名、变量名 | 英文原样，机器认的符号改不了 |

这不是"最后用中文回答"，是**过程本身就全程中文**。中途冒出英文思考算违规。

看不懂英文报错不算违规，但**必须翻译成中文再说**，不能原样甩给你。

## 安装

```bash
npm i -g ps2-game-hanhua
```

装完在对话里说 **「开始汉化」** 就能触发。

### 其他参数

```bash
ps2-game-hanhua --dir <路径>   # 装到指定目录，默认 ~/.dsh/skills/
ps2-game-hanhua --check       # 只检查装没装，不动文件
ps2-game-hanhua --force       # 已经装了，强制覆盖
ps2-game-hanhua --help        # 看这个帮助
```

### 不用包管理器

去 [Releases](https://github.com/yymz072-beep/ps2-game-hanhua/releases) 下载 zip，解压到 `~/.dsh/skills/` 目录即可。

目录结构是这样：

```
~/.dsh/skills/ps2-game-hanhua/
├── SKILL.md
└── references/
    └── technical-notes.md
```

## 它是什么

你说一句「开始汉化」，它会按固定流程推进：

```
问清需求 → 摸底分析 → 定方案 → 逐块执行 → 验收
```

每个需要你拿主意的地方，它都会停下来问，并且把选项的好坏都写清楚。

---

## 五条规矩

开头那条**全程说中文**是第零条，和下面五条并列，同样不能破。

### 1. 不许自己做决定

动手前先问："这个决定是用户做的还是我做的？"

答不上来就停下来问。

明确列了不能做的事：

- 替用户选方案
- 猜用户想要什么
- 觉得"这样应该可以"就动手
- 说"我先这样做，不行再改"

### 2. 说人话

不堆术语。技术名词每次出现都要解释，不只是第一次。

| 术语 | 它会说成 |
|---|---|
| 借位法 | 借用游戏里暂时用不到的格子，把中文字画进去 |
| 点阵字库 | 用一个个小方块拼出来的字，像马赛克 |
| 等长替换 | 换字时字数不能变，变长了后面的内容会全部错位 |
| xdelta | 只记录"改了什么"的小补丁，配上原文件就能还原 |

表里没有的词，它得自己现编一个解释，然后补进表里。

### 3. 选项摆清楚

每个选择都给至少两个方案，标注推荐项，好处坏处都写，不藏着掖着。

### 4. 问得少，说得短

一次只问 1~3 个问题，最好 2 个。回答控制在一屏能看完。

重点用加粗标出来，让人扫一眼就抓到关键。

### 5. 查到底，别绕过去

> 不是所有流传的方法都是正确的，你之前用过的方法也可能是错的。

遇到问题先找根源，能说出"为什么会错"才算真解决。真查不下去才考虑绕过，而且要明说是"绕过"不是"解决"。

## 流程概览

### 阶段零：开工前问清楚

分三批问，每批一到两个问题：

1. 游戏名 + 镜像路径
2. 汉化程度（只翻文字 / 加图片 / 全都要）+ 翻译谁来
3. 字库怎么办

### 阶段一：摸底

只看不动。统计文本量、图片数量、字库格式，出一份报告给用户看。

### 阶段二：带数据确认方案

拿着摸底结果问，比空问有效。

### 阶段三：逐块执行

每改一处立刻从成品读回验证。遇到看不懂的现象停下来描述，不猜着改。

### 阶段四：验收

先跑一遍测试清单（10 个场景），再出验收报告。

## 内置的技术积累

`references/technical-notes.md` 里是实际项目中踩出来的经验：

- 镜像三层嵌套的偏移换算
- 对话脚本的两种格式和提取器写法
- 点阵字库格式推算公式
- 借用空闲格子的规则
- 图片容器可能有多张图
- 颜色通道可能是红蓝反的
- 补 NUL 还是补空格要看游戏
- 标点符号在日文编码里可能编不出来
- 12 像素以下的字为什么不能加描边

SKILL.md 里还有：

- 写回的六条铁律
- 13 条故障速查
- 汉化测试清单
- 专有名词管理
- xdelta 补丁制作与回环验证
- 发布前的检查表

**注意**：具体偏移来自一个特定游戏，换游戏必须重新摸底，但格式规律和陷阱是通用的。
